# Бот «Разбор по глазам и ладони» — инструкция по запуску

## Что нужно сделать, по порядку

### Шаг 1. Получить токен бота у @BotFather

1. Открой Telegram, найди **@BotFather** (это официальный бот Telegram).
2. Напиши ему `/newbot`.
3. Придумай имя бота (то, что видят люди), например: `Разбор по глазам и ладони`.
4. Придумай username бота — обязательно заканчивается на `bot`, например: `annamahra_reading_bot`.
5. BotFather пришлёт тебе **токен** — длинную строку вида
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   Это и есть `BOT_TOKEN` — никому его не показывай, это как пароль от бота.

### Шаг 2. Узнать свой личный chat_id (куда бот будет слать заявки)

1. В Telegram найди бота **@userinfobot**.
2. Напиши ему что угодно (например `/start`).
3. Он пришлёт тебе твой **Id** — это число, например `987654321`.
   Это и есть `ADMIN_CHAT_ID`.

### Шаг 3. Разместить бота на хостинге (чтобы работал круглосуточно)

Проще всего — **Railway.app**, там есть бесплатный старт и не нужно уметь
программировать:

1. Зайди на **railway.app**, зарегистрируйся (можно через GitHub-аккаунт —
   если его нет, можно создать за 2 минуты на github.com).
2. Создай новый проект → **Deploy from GitHub repo** (сначала загрузи туда
   папку с файлами `bot.py`, `requirements.txt`, `payment_card.png` —
   через сайт github.com можно просто перетащить файлы в новый репозиторий,
   кнопка "Add file → Upload files").
3. В настройках проекта на Railway найди раздел **Variables** и добавь:
   - `BOT_TOKEN` = токен из Шага 1
   - `ADMIN_CHAT_ID` = число из Шага 2
4. Railway сам определит, что это Python-проект, установит зависимости из
   `requirements.txt` и запустит `bot.py`.
5. Готово — бот работает 24/7, даже если у тебя выключен телефон/компьютер.

*Альтернативы Railway: Render.com (Background Worker, платно от ~$7/мес),
или свой VPS (Beget Cloud, Timeweb Cloud — от ~200₽/мес), если хочешь
полный контроль.*

### Шаг 4 (необязательно). Проверить локально на своём компьютере

Если хочешь сначала просто посмотреть, как бот работает, у себя на
компьютере (это НЕ будет работать 24/7, только пока открыт терминал):

```bash
pip install -r requirements.txt
export BOT_TOKEN="твой_токен"
export ADMIN_CHAT_ID="твой_id"
python bot.py
```

(на Windows вместо `export` используй `set`).

## Как это работает для клиента

1. Клиент находит бота по username (`@annamahra_reading_bot` или как ты
   его назвала) и жмёт **/start**.
2. Выбирает пакет (глаза / ладонь / комплекс).
3. Присылает фото и свой главный вопрос.
4. Бот показывает ему карточку с реквизитами для оплаты.
5. Тебе в личку от бота приходит заявка: фото, вопрос, username клиента,
   его chat_id.

## Как ты отвечаешь клиенту

Раз ты сама делаешь разбор вручную, есть два способа его отправить:

- **Проще всего** — если у клиента есть публичный `@username`, просто
  написать ему напрямую в личку в Telegram, как обычному человеку.
- **Через бота** — если username нет (или хочешь, чтобы всё шло от имени
  бота), напиши самому боту команду:
  ```
  /reply 987654321 Вот твой разбор: ...текст разбора...
  ```
  где `987654321` — это chat_id клиента (бот прислал его вместе с заявкой).
  Бот перешлёт этот текст клиенту от своего имени.

## Важно

- Бот НИЧЕГО не анализирует и не генерирует сам — весь текст разбора
  придумываешь и пишешь ты. Это инструмент только для приёма заявок,
  фото и оплаты.
- Оплату бот тоже не принимает автоматически — только показывает номер
  телефона для перевода (как договорились). Приём денег остаётся ручным.
- Файл `payment_card.png` должен лежать в той же папке, что и `bot.py` —
  без него бот просто не пришлёт клиенту карточку с реквизитами (но
  остальное будет работать).
